## Project name 
Grass Cutter Escape Game
## Description
This is my hobby project for practicing game development with Godo4 engine and C#. At the same time, I practice digital drawing because I plan to draw all or almost all assets for the game with Krita by myself. 
This 2D game is about a block of grass who has one job: Escape the lawn mower and reach as many not yet mown grass areas as possible to warn other blocks of grass. This idea is based on the theory that smell of fresh newly cutted grass 
is actually warning sign for other grass areas that soon there will be someone to mowning the lawn.
